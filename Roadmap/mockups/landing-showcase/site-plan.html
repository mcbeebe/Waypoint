Rules every page follows
  • Screens are built in code with a made-up family (“Maya”). No real child, parent, staff, email or phone number, ever.
  • One main button everywhere: “Start free.” Free tools end at the same button, and the tool a visitor came from goes with them into sign-up.
  • Free tools run only in the browser. Tests fail if a tool sends or stores anything.
  • Copy tests block claims like “best” or “#1”, user counts, and any price or integration we haven’t confirmed.
  • Every legal point is cited to a source the site has already verified.
Decisions needed

Six calls, and which pages wait on each

  1. Which prices are real?The site says Plus is $4.99 a month and Pro $9.99. The app’s code has one Premium plan at $99 a year or $14.99 a month. Blocks the pricing page.
  2. What’s free?The site puts deadline alerts in Plus and letters in Pro. The app lists core letters and the request tracker as free. Blocks any Free or Premium labels.
  3. Spanish.The homepage says “En español” and pricing says “full parity”, but the website has no Spanish pages. Change the wording to “The app speaks Spanish”, or plan Spanish pages?
  4. The four families in the hero tabs.Proposed: just diagnosed (0–5), the IEP years, benefits and money, turning 18.
  5. FAQ answers.I’ll draft them from what the pricing, privacy and about pages already say, and you approve the wording.
  6. When the goal check shows up in search.Unhide it from search and the footer when its PR merges, or after a separate copy review?
