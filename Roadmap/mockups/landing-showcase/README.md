the feature tabs and the IEP goal check both work.

- **Sample family is fictional ("Maya").** The owner's screenshots were used as
  layout reference only; no real child, parent, staff name, email, phone
  number, or district appears.

  carry no real data, stay crisp, and can be translated (es).

  the site (Ed Code §56321, §56343.5, §56345(a)(2); 34 CFR §300.320(a)(2)).
