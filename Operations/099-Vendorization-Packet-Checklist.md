# 099 Vendorization Packet — Checklist (W0 gating task)

**Why:** transition supports (up to 40 hrs/family, RC-paid) bill under service code 099, which requires vendorization with the home Regional Center (RCEB). Ongoing FMS-invoiced facilitation does NOT depend on this — but Phase-1 transition revenue does. Target: packet submitted within W0 (weeks 1–2).

**Route (corrected Aug 24, 2026):** classic vendorization packet submitted **directly to RCEB's vendorization unit** — NOT the Provider Directory. Per DDS (https://www.dds.ca.gov/rc/vendor-provider/vendorization-process/), entities seeking to serve Self-Determination Program participants **cannot apply in the Provider Directory** except FMS codes 315–317; the Directory's standardized digital application therefore does not cover 099. Regional centers vendor SD Supports providers via the traditional packet (DS 1890, DS 1891, Qualifications & Agreement form, Conflict of Interest form, BAA/HIPAA form, HCBS Provider Agreement, W-9 — per RC vendorization pages for code 099). Vendorizing RC: RCEB (Waypoint's catchment). One vendorization statewide: per the July 2, 2024 DDS guidance, separate vendorization is **not** required in each catchment for General SD Supports; RCs must use code 099 when vendoring new providers for this service. **Confirm the exact intake route and current forms with RCEB before assembling — DDS letter question #6.**

**Alternative route (no vendorization):** the July 2024 guidance also allows 099 pre-enrollment supports through **Participant-Directed Services** (code 099, sub-code PDS) — the family selects Waypoint as a qualified provider and the FMS-style payment mechanics apply. This is a per-family fallback that works before (or without) vendorization; it doesn't scale like a vendor number but de-risks Phase-1 revenue while the packet is in review.

## Documents to assemble

- [ ] Legal entity formed (CA corporation w/ benefit election — see incorporation task) + EIN
- [ ] DS 1890 (Vendor Application)
- [ ] DS 1891 (Applicant/Vendor Disclosure Statement)
- [ ] Qualifications & Agreement form, Conflict of Interest form, BAA/HIPAA form, HCBS Provider Agreement (RC-specific — get RCEB's current set at the intake call)
- [ ] W-9
- [ ] Program design for General Self-Directed Supports (code 099): service description matching DDS Enclosure A (July 2024 guidance) — transition supports for SDP entrants: orientation follow-through, budget worksheets, spending-plan drafting, FMS selection support; delivery settings; staff qualifications; supervision
- [ ] Staff qualifications & résumé(s); background-check documentation as required by RCEB's program-design standards (confirm exact standard with RCEB — DDS question #2)
- [ ] Liability insurance certificate (confirm required limits with RCEB)
- [ ] Rate documentation: 099 is negotiated/schedule-based per RC — confirm RCEB's current 099 rate at application
- [ ] Physical-location note: in-catchment office requirement repeals 1 Jan 2027 (SB 163); if applying before then, confirm RCEB's current interpretation for a home-office/remote provider

## Sequence

1. Incorporate + EIN (parallel: UEI/SAM if pursuing grants)
2. RCEB vendorization unit intake call — confirm the 099 application route (classic packet, per the SDP Provider-Directory exclusion) and current forms; ask DDS questions #2/#3/#6 in the same conversation
3. Draft program design (reuse Enclosure A language; keep scope tightly to transition supports)
4. Assemble and submit the packet directly to RCEB; track status in-app (PRD D1: vendor packet status is a first-class record)
5. In parallel from day one: offer 099 via the **PDS route** for the first pilot families so transition revenue doesn't wait on the vendor number
6. On approval: confirm with RCEB whether any Provider Directory registration applies (SDP codes are Directory-excluded except FMS 315–317) and how QIP applies to the 099 rate (new vendors typically start at 90% of rate until validated; budget accordingly)

**Reality check:** RCs cannot deny for "lack of need" (Title 17 §54322) but are never obligated to authorize purchases. The per-family 099 authorizations still come from service coordinators — relationship work, tracked per family in-app.
